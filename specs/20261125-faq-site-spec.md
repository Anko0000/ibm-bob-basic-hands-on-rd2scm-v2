## 背景・目的

`qa.md` に記載されたBobに関するFAQコンテンツ（英語）をもとに、日本語のFAQ Webサイトを作成する。
バックエンドなしの静的ファイルのみで動作し、ブラウザで即時閲覧できることを目的とする。

## 現在の挙動

`qa.md` にFAQ内容（英語）が記載されているが、Webサイトとして公開されていない。

## 期待する挙動

`index.html` をブラウザで開くと日本語のFAQサイトが表示される。
カテゴリ別のセクション構成とアコーディオン形式のQ&A、キーワード検索機能を持つ。

## 主な仕様

1. **コンテンツ:** `qa.md` のFAQ全項目（20件）を日本語に翻訳して掲載する。
2. **カテゴリ構成:** 以下の4カテゴリをセクションとして分割表示する。
   - 一般（General）: 5件
   - 使い方（Usage）: 8件
   - 高度な機能（Advanced Features）: 2件
   - トラブルシューティング（Troubleshooting）: 2件
3. **Q&A表示:** 各Q&Aはアコーディオン形式（クリックで回答を開閉）で表示する。初期状態は全項目閉じた状態。
4. **検索機能:** ページ上部に検索ボックスを設置し、テキスト入力に応じてQ&AをリアルタイムにJavaScriptで絞り込む。検索対象は質問文・回答文の両方。検索結果がゼロ件の場合は「該当するFAQが見つかりませんでした」と表示する。
5. **デザイン:** IBM Carbon Design System に準じたスタイル（IBMブルー基調）。外部CDNは使用せず、CSS/JSはHTMLファイルに直接埋め込む。
6. **レスポンシブ対応:** PC（1024px以上）とスマートフォン（768px以下）で適切に表示が変わる。
7. **ファイル構成:** 単一の `index.html` ファイルにHTML・CSS・JSをすべて埋め込む。

## 制約・非機能要件

- 静的ファイルのみで動作すること（サーバー不要、`file://` プロトコルで動作）
- 外部CDNへの依存なし（オフライン環境でも動作すること）
- モダンブラウザ（Chrome, Firefox, Safari, Edge の最新版）で動作すること

## UI・画面仕様

### 対象画面

FAQ一覧ページ（1ページ完結）

### 画面構成・表示項目

| エリア | 内容 |
| --- | --- |
| ページヘッダー | サイトタイトル「よくある質問 (FAQ)」、サブタイトル「IBM Bobに関するよくある質問をまとめました」 |
| 検索エリア | 検索ボックス（プレースホルダー「キーワードで検索…」） |
| コンテンツエリア | カテゴリセクション × 4（各セクションにアコーディオンQ&Aリスト） |
| フッター | 著作権表記 |

各アコーディオン項目：
- 閉じた状態: 質問文（Q:〜）＋右端に開閉アイコン（▼）
- 開いた状態: 質問文＋回答文（箇条書きを含む場合はリスト形式で表示）

### 操作・画面遷移

- アコーディオンの質問行をクリック → 回答が展開/折りたたまれる
- 検索ボックスにテキストを入力 → 質問・回答の両方に対してキーワードマッチする項目のみを表示（カテゴリセクションも絞り込まれる）
- 検索ボックスをクリア → 全項目を再表示

### 表示状態

| 状態 | 表示内容 |
| --- | --- |
| 初期表示 | 全カテゴリ・全Q&Aを表示。アコーディオンは全て閉じた状態 |
| 検索中 | 入力キーワードにマッチするQ&Aのみ表示。マッチしないカテゴリセクションは非表示 |
| 検索結果ゼロ件 | 「該当するFAQが見つかりませんでした」のメッセージを表示 |

### 入力・バリデーション

- 検索ボックス: テキスト入力のみ。バリデーションなし。大文字小文字を区別しない。

### デザイン要件

- IBM Carbon Design Systemに準じた配色・タイポグラフィを採用
  - プライマリカラー: `#0f62fe`（IBM Blue 60）
  - 背景: `#ffffff`（白）
  - テキスト: `#161616`
  - セクションヘッダー背景: `#f4f4f4`
- フォント: IBM Plex Sans（CDN不使用のため、`system-ui` フォールバックを使用）
- アコーディオンのボーダー・区切り線は `#e0e0e0`
- PC: 最大幅 `960px` でセンタリング
- スマートフォン: 全幅表示、フォントサイズ調整

### 参考資料

- IBM Carbon Design System: https://carbondesignsystem.com/
- Carbon カラーパレット: https://carbondesignsystem.com/elements/color/tokens/
